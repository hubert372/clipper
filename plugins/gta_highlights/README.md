# GTA highlights (reguły wykrywania)

`taxonomy.py` pochodzi bez zmian z projektu
[Grand-Theft-Auto-6-Clips-Kitty-Plugin](https://github.com/ColinGPT9/Grand-Theft-Auto-6-Clips-Kitty-Plugin)
(wersja 0.4.1, commit 17e710c), autor ColinGPT9, licencja MIT (plik `LICENSE`).

Clipper używa z niego reguł rozpoznawania wydarzeń GTA w tym, co mówi streamer
(pościg, kraksa, kaskada, strzelanina, chaos z NPC, koniec misji). Reszta wtyczki jest
napisana pod SDK Clips Kitty, więc nasłuch na żywo i wyzwalanie klipów są po stronie Clippera.
Reguły obejmują angielski i częściowo hiszpański. Autor zaznacza, że na rozgrywce z GTA VI nie były testowane.
